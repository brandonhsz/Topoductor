The Topo CLI is the `topo` command-line interface for scripting a running Topo editor from any shell. Use it to create and inspect worktrees, drive agent terminals, open files and diffs, automate the built-in browser, run scheduled automations, share HTML/Markdown artifacts, and control Topo-native tools from scripts or AI agents.

It ships with the desktop app; register it under [Settings → General → Topo CLI](/docs/settings). On Linux the command is `topo-ide` — see [Install → Linux](/docs/install#linux).

Agents can install the matching Topo CLI skill with:

```bash
npx skills add https://github.com/brandonhsz/Topoductor --skill topo-cli
# headless / no Settings UI:
topo skills install --skill topo-cli
```

See [Skills registry & MCP](/docs/cli/skills) for every installable Topo skill, including `topo skills install` / `topo skills update`.

## Install & verify

```
command -v topo
topo status --json
```

## Worktree commands

```
topo worktree ps --json
topo worktree create --repo id:<repoId> --name my-task --issue 123 --json
topo worktree create --repo id:<repoId> --name review-pr-123 --pr 123 --json
topo worktree current --json
topo worktree set --worktree active --comment "reproduced bug" --json
topo worktree set --worktree active --gitlab-issue 42 --gitlab-mr 77 --json
topo worktree set --worktree active --pr null --json
topo worktree rm --worktree id:<id> --force --json
```

For selectors, setup flags, parent/child worktrees, and the broader command map, see [Topo CLI reference](/docs/cli/reference).

## Terminal commands

```
topo terminal list --json
topo terminal read --json
topo terminal send --text "continue" --enter --json
topo terminal wait --for tui-idle --timeout-ms 30000 --json
topo terminal create --worktree path:/projects/app --command "npm test" --json
topo terminal split --direction vertical --command "npm run dev" --json
```

For tracked multi-agent work, use [Orchestration](/docs/cli/orchestration) instead of plain terminal prompts.

## File commands

Open files and diffs as tabs in their Topo worktree from a shell. They open without changing what you are looking at; add `--focus` to be brought to the file:

```
topo file open src/App.tsx
topo file diff src/App.tsx --staged
topo file open-changed --mode both
```

Use `--worktree <selector>` when the shell's current directory is not inside the target worktree.

## Browser profiles

Browser profiles isolate tab session state, so a script or agent can test with different cookies, local storage, and logged-in identities. The CLI exposes profile commands under `topo tab profile`; start with `topo tab profile list --json`, then use `create`, `set`, `clone`, or `use-default` as needed.

## Scheduled automations

Use `topo automations` to create, inspect, run, and remove scheduled Topo tasks from a shell. Start with [Scheduled automations](/docs/cli/automations) when you want a recurring prompt to run against a repo or an existing worktree.

## Artifacts

Share HTML or Markdown as public view links through the signed-in Topo account (`topo artifacts share|update|list|delete`). Publishing is **opt-in** under Settings → Artifacts. Command details: [CLI reference → Artifacts](/docs/cli/reference#artifacts).

## Browser automation

The CLI also drives the built-in browser with a snapshot-interact-re-snapshot loop:

```
topo goto --url https://example.com --json
topo snapshot --json     # returns refs like @e1, @e3
topo click --element @e3 --json
topo fill --element @e1 --value "user@example.com" --json
topo screenshot --json
```

For responsive browser checks, switch the active tab to a named device profile:

```
topo set device --name "iPhone 12" --json
topo screenshot --json
```

## Mobile emulator

The CLI can also drive an iOS Simulator through Topo's mobile emulator bridge. It is scoped to the active worktree, so agents and scripts can attach a simulator, list the worktree's attached devices with `topo emulator list`, tap normalized coordinates, type text, send gestures, rotate the device, and shut it down without leaving Topo.

```
topo emulator list --json
topo emulator attach "<device-name-or-udid>" --json
topo emulator tap 0.5 0.7 --json
topo emulator type "hello" --json
topo emulator gesture '[{"type":"begin","x":0.5,"y":0.8},{"type":"move","x":0.5,"y":0.4},{"type":"end","x":0.5,"y":0.2}]' --json
topo emulator rotate landscape_left --json
topo emulator kill --json
```

Use `--worktree <selector>`, `--device <udid-or-name>`, or `--emulator <id>` when a script needs an explicit target.
